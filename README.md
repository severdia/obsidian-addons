# Obsidian Notes Browser

A simple notes browser for Obsidian that provides a column browser experience.

To build and install:

1. Install NodeJS and NPM.
2. Navigate to the repo using a terminal.
3. Run `npm install`
4. Run `npm run build`
5. The plugin will be available under a folder called `build` inside the local repo. Put that inside the Obsidian plugins folder in obsidian and enable it in the Obsidian settings.



Run `npm install --legacy-peer-deps` if needed.
